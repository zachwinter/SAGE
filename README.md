# SAGE

An agent for your CLI, built (for now) with the LM Studio SDK.

## Installation

Install `node` and `gum` if you don't already have them.

```bash
brew install node gum
```

If you don't have `brew` (Homebrew), install it first with:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Then, clone the project and install:

```bash
git clone https://github.com/zachwinter/sage.git
cd sage
npm i
```

Link:

```bash
npm link
```

Then run it!

```
sage
```
